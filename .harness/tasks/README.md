# Task Templates

Create one task file per lane when coordination needs more than the board.

## Filename

`YYYYMMDD-short-slug.md`

## Template

```md
# Task: <short outcome>

Owner:
Write scope:
Do not edit:

## Target Result

## Inputs

## Steps

## Validation

## Handoff Notes
```

## Rules

- Keep tasks additive unless explicitly approved otherwise.
- Prefer paths and commands over prose.
- Record skipped validation with the reason.
