# Handoffs

Use handoffs when a lane stops before full completion or needs another agent to continue.

## Filename

`YYYYMMDD-HHMM-from-to-scope.md`

## Template

```md
# Handoff: <scope>

From:
To:
Current status:

## Changed Files

## Evidence

## Known Blockers

## Safe Next Action
```

## Rules

- Name files precisely.
- Separate evidence from guesses.
- Do not assign work outside the receiver's approved scope.
