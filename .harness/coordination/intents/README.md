# Intent Notes

Use intent notes before touching shared or review-sensitive files.

## Filename

`YYYYMMDD-HHMM-owner-scope.md`

## Template

```md
# Intent: <scope>

Owner:
Planned files:
Reason:
Expected validation:
Conflict window:
```

## When Required

- Shared files with active edits.
- Any change that may alter validation commands.
- Any change that could be confused with runtime behavior work.
